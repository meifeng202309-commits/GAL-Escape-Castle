# Parkour v1.2

Skill 1 — Modify.

## Changes from v1.1
- Increased starting running speed.
- Increased maximum speed and acceleration.
- Increased obstacle spawn frequency.
- Jump, slide, collision rules, and visual design remain unchanged.

## Verification
Check that:
1. the game starts faster than v1.1;
2. obstacles appear more frequently;
3. jumping still clears low hurdles;
4. sliding still avoids high obstacles;
5. collision still ends the game.

## Run
Open `src/index.html` in a web browser.

## Controls
- Space / Arrow Up: jump
- Arrow Down: slide
- R / Space after game over: restart
