# Parkour v1.0

Baseline web parkour game for the Vibe Coding course.

## Gameplay

- Player continuously runs forward.
- `Space` / `Arrow Up`: jump over low hurdles.
- `Arrow Down`: crouch/slide under high obstacles.
- Collision with an obstacle ends the game.
- Speed gradually increases.
- `R` or `Space` after Game Over restarts the game.

## Run

Open `src/index.html` in a modern web browser.

## Project structure

- `src/` — executable source.
- `assets/` — visual/audio assets added in later iterations.
- `docs/` — design notes and project documentation.
